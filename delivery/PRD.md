# AIStudio 商品内容工作台 PRD

版本：2026-10-23，开发中。产品包含电商图片与商品广告视频两条线，目标是商品展示、真实卖点和跨场景商品一致性。此前短剧仅保留为历史技术验证。

## 已确认需求

- 图片页沿用现有功能；两条线共用项目、素材、队列与导出，切换不丢状态。
- 一个广告需求拆成多个场景，全片共用同一商品参考；人物可选，出镜时也共用人物参考。
- 整组关键帧放在一起检查商品、人物与衔接，确认后生成视频，再合并成片。
- 自由画布主要展示素材、关键帧与视频实际结果及其关联；设置放在工具区，不做固定步骤圆点和大量设置节点。
- 用户只说本次修改，继承其余设定；只标记相关场景，不自动整组重跑。
- 优化后的需求先预览确认，不自动提交生成，不为拆解增加不必要的模型调用。

## 第一阶段实现与边界

规则及模板在 skeleton/config/ad_prompts.json。商品外形、颜色、材质、结构、Logo与包装沿用固定参考；未知的卖点、价格、优惠、性能及功效保留待补充，不编造成事实。相邻画面只辅助衔接，不能替代原始商品参考。

提供商品展示、AIDA、FAB、PAS四套模板。默认商品展示；其余按已提供的信息选择。每套首版有三个场景草稿，后续可编辑。当前采用固定模板整理，保留原始需求与商品事实，不宣称已验证最优效果。

广告项目保存在当前浏览器，可随项目 JSON 导出；素材、生成文件与任务在本机后端保存。新版商品广告前端已接入真实关键帧、视频及合并接口，旧短剧画布保留在历史入口。规则通过共用参考和提示词传递，不承诺模型必然遵守，仍需人工验收。

尺寸、分辨率和时长在首次意图输入区直接选择，完整设置与规则窗口保留并双向同步。支持 16:9 / 9:16 / 1:1、480P / 720P / 1080P；首版三个可编辑场景，总时长预设15/30/60秒，支持自定义6–90整数秒；三个场景均分整数秒，余数按场景顺序分配（如20秒→7/7/6秒），每段2–30秒。输入区和设置窗口同步，非法秒数不可提交。广告关键帧请求匹配画幅，合并按所选目标尺寸输出 MP4 / 30fps / 无声，不拉伸商品。新增参数已接入代码，尚未逐组合实跑质量验收。

前端入口为 http://127.0.0.1:8765/ 的商品广告 tab；8770 保留为独立设计稿，不是正式生成入口。

## 验收

新广告流程单独验收：同一商品跨场景保持、卖点不新增事实、关键帧整组可审、视频可播可导出、失败可见、1280/1440不溢出。评分草案与历史证据见评测文档。

不做Agent、DeepSeek、本地模型、多SKU、队列抢占或复杂剪辑；不扩展人物短剧。当前为开发快照，不是正式上线版本。
