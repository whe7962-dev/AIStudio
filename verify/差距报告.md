## 它现在是什么

这是「端侧AIStudio」的 Python 后端骨架，正式产品是原生 macOS 桌面画布应用（Swift/SwiftUI），本包通过本地 HTTP 提供推理与图像处理管线。骨架用 FastAPI 承载工具分发、权限、钩子、项目图、任务队列与观测，并内置一条确定性的电商闭环 demo（stub provider 可离线跑通）。8 个领域工具覆盖素材摄入质检、一致性锚点、生图、保真度评分与批量质检、后处理打包、项目图编辑、资产库、模型管理。红线是默认不出网（仅放行 demo 生图域名）、无云端兜底、不静默失败（重试 + 降级链 + 标记 degraded）。大量真实能力（本地模型推理、渠道规格、质检阈值、模型下载热切换）仍是占位实现，README 已标注为待确认项。
