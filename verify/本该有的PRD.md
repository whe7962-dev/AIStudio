# 端侧AIStudio（skeleton 后端骨架）

> 给没有设计团队的电商运营和中小商家，在本地设备上把商品实拍批量变成符合各电商平台规格的素材包，解决请不起设计师、素材不敢上传云端、多 SKU 风格漂移的痛点

## 目标

把「生成一张图」变成「可批量、可复用、可交付的生产线」。成功标准：北极星 = 首轮采纳率（每 SKU 默认 4 张草稿中直接选用或仅微调即选用的比例）、初稿到定稿耗时（单 SKU × 5 平台 p95 ≤ 30min，待实测）；过程指标 = 批次一致性分 ≥ 0.85、导出一次通过率 ≥ 90%、任务恢复率 100%（均待实测）。

## 用户

主用户：没有设计团队的电商运营和中小商家，单机单用户为主，以异步批处理方式使用（提交批量任务后等待草稿和终稿）。副用户（二期）：3–10 人短剧小团队。

## 核心闭环

电商闭环（V1）：新建 SKU → 上传 3–5 张实拍 → 自动抠图/质检 → 生成一致性锚点 → 选渠道模板 → 批量草稿 → 选优/局部重绘 → 终稿 → 后处理/导出 → 归档复用。核心细节：所有模块读写同一张项目图（DAG），改一个节点只重算下游，导出前需用户确认。

## 交付物

按渠道规格裁切、命名、打包的电商素材包（覆盖淘宝/天猫/京东/拼多多/抖音 5 个平台），以及可复用的项目图（DAG）和内容寻址资产库；交付前需用户确认导出。

## 边界

红线：用户上传的商品图、参考图、生成物默认永不离开设备，除用户显式勾选外不触发任何上传；全部推理在本地完成、无云端兜底（仅 demo 可用 API 验证链路）；不静默失败，降级必须可见。非目标：不做通用聊天助手、云端设计平台、云端协作、专业剪辑、模型训练平台；短剧二期也不做长片/配音/配乐。

## 约束

全部推理本地完成、无云端兜底；MVP 设备 = Apple Silicon 32GB 统一内存（NVIDIA 24GB VRAM 为二期/扩展）；原生 macOS App；延迟包络 = 草稿首图 p95 ≤ 10s、终稿单图 p95 ≤ 2min（均待实测）；单执行道 + 优先级队列 + 交互插队 + step 边界抢占 + 每 N 步 checkpoint + job journal 崩溃续跑 + OOM 降级链；推理层做 provider 抽象，正式版切本地。
